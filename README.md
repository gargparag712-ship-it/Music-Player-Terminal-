# 🎵 CLI Music Player

A simple command-line music player built using **Node.js** and **VLC**.  
It allows users to play and control local music directly from the terminal.

## ✨ Features

- Play / Pause songs
- Next / Previous song
- Navigate songs using arrow keys
- Shuffle mode
- Repeat mode
- Seek forward / backward
- Live progress bar
- Elapsed time / total duration
- Playback history
- Automatic next song

## 🛠️ Tech Stack

- Node.js
- JavaScript
- VLC Media Player
- File System (`fs`)
- Child Process
